# P2 - M0 Bayesian regression

Reproducible code for the M0 baseline regression: JAGS and hand-written Gibbs samplers, convergence diagnostics, and pointwise log-likelihoods.

- M0_functions.R: core samplers and helpers
- M0_prepare.R: data cleaning and covariates
- M0_run.R: main runner (selftest / real)
- M0_selftest.R: one-file self-test
- M0_make_share_loglik.R: shrink loglik files for GitHub
