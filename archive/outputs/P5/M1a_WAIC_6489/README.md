## Model and numerical checks

`y_i ~ Normal(alpha, tau^2 + s^2 / n_i)`, with game-level latent rating integrated out. Priors: `alpha ~ N(6.4, 1^2)`, `s ~ Uniform(0.5, 3)`, `tau ~ half-Cauchy(0,1)`. Common pseudo-votes `m = s^2/tau^2`.

| Quantity | Result |
| --- | ---: |
| Training rows | 6,489 |
| MCMC | 4 chains × 3,000 retained draws |
| Maximum reported R-hat | 1.00664 |
| Minimum reported ESS | 2,263 |
| alpha posterior mean | 6.43495 |
| s posterior mean | 2.96551 (near upper prior bound) |
| tau posterior mean | 0.87445 |
| m posterior mean | 11.50665 (prior-sensitive) |
| Pointwise log-likelihood sampled | 500 draws × 6,489 games; 125 drawn from each chain |
| lppd | −8,745.83569 |
| p_WAIC | 2.23850 |
| elpd_WAIC | −8,748.07419 |
| **WAIC = −2 × elpd_WAIC** | **17,496.14838** |
| Approximate SE for single-model WAIC | 133.22 |

The 500-draw game-level log-likelihood was numerically finite and its columns were verified in the same order as the uploaded IDs. This WAIC assesses development-sample fit, **not** held-out predictive performance. It cannot be compared to a WAIC calculated on different games, or treated as a full three-model WAIC comparison. P4 likelihood integrates latent `theta_i` but conditions on named designer effects; state that predictive target limitation explicitly in the eventual comparison.
